# Contributing

Pull requests are welcome, including ones written with AI tools or by agents.

- Pick an open issue and say `Closes #<n>` in the PR. Each issue states when it is done.
- Use pnpm. Run `pnpm lint`, `pnpm check` and `pnpm test:all` before opening the PR, and add tests for what you change.
- Keep a PR to one issue.
- Commit only real data you are allowed to publish. Anonymize activity exports first: titles, IDs, notes and gear stay out of the repo.

Every PR is reviewed before it merges. The maintainer may push commits to your branch to finish it, then squash-merge it with you as the author.
